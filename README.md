# Artheim - Art Education Platform

An interactive, gamified art education platform supporting multiple curriculum frameworks (NCAS, IB MYP, IGCSE).

## Features

- 🎮 **Gamified Learning** - Quest-based progression with map exploration
- 📚 **Multiple Frameworks** - NCAS, IB MYP, and IGCSE support
- 👨‍🏫 **Teacher Dashboard** - Student management, grading rubrics, analytics
- 🎨 **Student Portfolios** - Upload artwork, track progress, earn badges
- 📊 **Analytics** - Class performance, student progress tracking
- 🖨️ **Print Reports** - Generate student progress reports
- 📝 **Custom Quests** - Teachers can create their own quests

## Tech Stack

- Frontend: HTML, CSS, JavaScript (Vanilla)
- Backend: Supabase (PostgreSQL, Auth, Storage)
